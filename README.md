# 🐕 Landing Page - Adestramento Canino

## 📖 Sobre
Landing page desenvolvida para divulgação de serviços de adestramento canino, com foco em apresentação profissional e captação de clientes.

## 🛠 Tecnologias
- HTML5
- CSS3

## 🎯 Funcionalidades
- Apresentação do profissional  
- Exibição dos serviços oferecidos  
- Cards com descrição dos serviços  
- Galeria de fotos de treinamentos  
- Layout responsivo  
- Botão de contato direto via WhatsApp  

## ▶️ Como executar
Abra o arquivo `index.html` no navegador
